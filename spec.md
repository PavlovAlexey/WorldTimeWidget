# WorldTimeWidget — техническая спецификация реализации

**Дата:** 2026-09-14
**Статус:** к реализации
**Дизайн:** см. [design_brief.md](design_brief.md) (текстовое описание) и сам файл в Penpot — `http://localhost:9001`, файл с бордами, страница «WorldTimeWidget — дизайн (Fluent/Mica)», 5 артбордов (01 · Основной вид, 02 · Наведение курсора, 03 · Добавление города, 04 · Режим редактирования списка, 05 · Меню). Все цвета/радиусы/тени/шрифты — из этого дизайна, см. раздел «Результат отрисовки» в design_brief.md для точных значений (surface `#F3F3F3 @78–94%`, accent `#0078D4`, textPrimary `#1B1B1B`, textSecondary `#6B6B6B`, divider `#000000 @6%`, радиус 8px/6px, drop-shadow blur 24–28 offsetY 8–10 чёрный 16–20%). Вместо Segoe UI (недоступен в самохостинге Penpot) в макете стоит Inter — в реализации использовать системный **Segoe UI Variable** (доступен из коробки на Windows).

## Стек и требования платформы

- **.NET 8, WPF**, `net8.0-windows`, только Windows (используем WinAPI-специфику: registry autostart, DWM/acrylic).
- Сборка **self-contained single-file** под `win-x64`, чтобы результат запускался на чужом ПК без установленного .NET Runtime:
  `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true`
- Инсталлятор: **Inno Setup** — один exe-установщик, устанавливает per-user (без прав администратора) в `%LocalAppData%\Programs\WorldTimeWidget`, создаёт ярлык в Пуске (+ опционально на рабочем столе), корректно прописывает деинсталлятор.
- Репозиторий/файлы кладём в `C:\cfgs\WorldTimeWidget\` (сейчас там только `design_brief.md` и этот файл): решение `WorldTimeWidget.sln`, проект `src/WorldTimeWidget/`, инсталлятор `installer/WorldTimeWidget.iss`, `README.md` с инструкцией сборки/публикации/установки.

## Функциональность

### Окно виджета (главный экран)
- Плавающее окно без рамки: `WindowStyle="None"`, `AllowsTransparency="True"`, `ShowInTaskbar="False"`, без иконки в панели задач и без системного трея (по решению из дизайна — только floating widget).
- Перетаскивание мышью за любую пустую область карточки (`DragMove()` по `MouseLeftButtonDown`, кроме кликов по интерактивным элементам).
- **Режим «поверх всех окон» — обязательно**: свойство `Topmost`, управляется тумблером в меню «Всегда поверх окон» (см. борд 05), **по умолчанию включено**. Переключение должно применяться сразу, без перезапуска, и сохраняться в настройках между запусками.
- Позиция окна на экране запоминается между запусками (сохранять X/Y в настройках при перемещении/закрытии).
- Список часовых поясов — вертикальные строки как на борде 01: слева индикатор день/ночь (точка) + название города, под ним дата в этом часовом поясе; справа крупное время + строка `UTC±N`. Домашний (системный, `TimeZoneInfo.Local`) часовой пояс всегда первой строкой, визуально подсвечен (полупрозрачная плашка), **не может быть удалён и не участвует в ручном перетаскивании порядка**.
- Индикатор день/ночь: точка тёплого цвета (amber, `#FFB900`) для локального часа 06:00–21:59 в этом поясе, индиго (`#5B5FC7`) для 22:00–05:59.
- Время в списке обновляется вживую: таймер выравнивается на границу минуты и тикает раз в минуту (не каждую секунду — отображаются только часы:минуты, секунды не нужны).
- При наведении курсора на карточку (только когда не в режиме редактирования) в правом верхнем углу появляются две круглые кнопки — «+» (открыть панель добавления города) и «⋯» (открыть меню) — борд 02.

### Добавление города (борд 03)
- Отдельная всплывающая панель (WPF `Popup`, привязана к главному окну, тот же визуальный стиль карточки) с полем поиска сверху и списком результатов (город, страна, `UTC±N`).
- Источник данных: статический курируемый список городов (≈50–80 популярных: столицы + крупные деловые центры), каждый замаплен на .NET `TimeZoneInfo.Id` (Windows time zone id, например «Russian Standard Time» для Москвы, «Tokyo Standard Time» для Токио). Поиск — по подстроке в названии города (регистронезависимо, поддержка кириллицы и латиницы, если разумно ограничиться одним языком UI — используем русский, как в дизайне).
- Клик по результату — добавляет город в список (если ещё не добавлен) и закрывает панель.
- Уже добавленные города не должны предлагаться повторно (либо скрываются из результатов, либо помечаются как «уже добавлен»).

### Режим редактирования списка (борд 04)
- Переключается через пункт меню «Изменить список». В этом режиме каждая (не домашняя) строка показывает слева хваталку (drag handle, иконка из точек) вместо индикатора день/ночь, справа — кнопку удаления «×» вместо времени.
- Перетаскивание строк мышью меняет порядок в списке (порядок сохраняется в настройках). Не обязательно делать анимацию pixel-perfect как в дизайн-тулах — достаточно рабочего reorder по drag (например, через `PreviewMouseMove` + `ObservableCollection` reindex), критерий приёмки — функциональность, а не плавность анимации.
- Внизу списка — пунктирная ghost-кнопка «+ Добавить город», открывающая ту же панель добавления, что и борд 03.
- Выход из режима редактирования — повторным пунктом меню («Готово»/тот же пункт меню переключателем) или кликом вне карточки.

### Меню «⋯» (борд 05)
Пункты сверху вниз, как в дизайне:
1. «Добавить город» — открывает панель добавления (борд 03).
2. «Изменить список» — включает режим редактирования (борд 04).
3. «Формат времени» с текущим значением («24ч»/«12ч») и шевроном — клик переключает между 24-часовым и 12-часовым форматом (простой toggle по клику, без необходимости в дополнительном подменю). Применяется сразу ко всем строкам, сохраняется в настройках.
4. Разделитель.
5. «Всегда поверх окон» — тумблер, управляет `Topmost` (см. выше), по умолчанию включён.
6. «Запуск при входе в Windows» — тумблер, включает/выключает автозапуск через ключ реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (per-user, без прав администратора). По умолчанию выключен.
7. Разделитель.
8. «Выход» (акцентный красный) — завершает приложение (`Application.Current.Shutdown()`). Это единственный способ закрыть приложение, так как нет ни рамки с крестиком, ни иконки в трее.

### Хранение настроек
- JSON-файл в `%AppData%\WorldTimeWidget\settings.json`: список добавленных `TimeZoneInfo.Id` в порядке отображения, формат времени (24/12), состояние «поверх всех окон», состояние автозапуска, последняя позиция окна (X/Y).
- При первом запуске (файла нет) — список городов пуст (кроме домашнего), Topmost=true, автозапуск=false, формат=24ч, окно по центру-справа основного экрана.

## Визуальное соответствие дизайну
- Точное совпадение цветов/радиусов/типографики — обязательное (значения зафиксированы в design_brief.md и в самом Penpot-файле, сверяться с ним).
- Эффект Mica/acrylic (полупрозрачность с блюром рабочего стола под окном) — если в разумные сроки реализуется через `DWM`/`Windows.UI.Composition` интероп — хорошо, это соответствует духу Fluent; если сложно/нестабильно на WPF — допустим fallback на просто полупрозрачную заливку без блюра фона (как статичный цвет с alpha), это **не блокирует приёмку**, но должно быть явно отмечено в отчёте как компромисс.
- Тени, скругления, отступы — по значениям из дизайна.

## Критерии приёмки

- [ ] `dotnet build` и `dotnet publish` (команда выше) проходят без ошибок.
- [ ] Опубликованный self-contained exe запускается на чистом окружении (без установленного .NET SDK/Runtime) — проверить явным запуском файла из папки публикации, не через `dotnet run`.
- [ ] Собран рабочий инсталлятор Inno Setup (`installer/WorldTimeWidget.iss` → `.exe`), устанавливает без прав администратора, создаёт ярлык в Пуске, деинсталлятор в «Программы и компоненты» работает и не оставляет мусора.
- [ ] Виджет — плавающее окно без рамки, перетаскивается, без иконки в панели задач.
- [ ] **«Всегда поверх окон» работает**: тумблер в меню реально меняет `Topmost`, по умолчанию включён, состояние сохраняется между перезапусками.
- [ ] Домашний часовой пояс всегда первой строкой, подсвечен, неудаляем.
- [ ] Добавление города через поиск, удаление и перетаскивание порядка в режиме редактирования — работают, изменения сохраняются в `settings.json` и восстанавливаются при перезапуске.
- [ ] Переключение формата времени 24ч/12ч работает и сохраняется.
- [ ] Автозапуск при входе в Windows — тумблер реально создаёт/удаляет ключ в реестре `HKCU\...\Run`.
- [ ] Индикатор день/ночи корректно меняется в зависимости от текущего времени в каждом поясе.
- [ ] Время в списке обновляется без перезапуска приложения.
- [ ] Визуально виджет узнаваемо соответствует дизайну (цвета, скругления, шрифт, расположение элементов) — сверка со скриншотами/Penpot-файлом.
- [ ] `README.md` в `C:\cfgs\WorldTimeWidget\` с шагами: сборка, публикация self-contained exe, сборка инсталлятора, установка на другом ПК.

## Вне рамок (не делать сейчас)

- Мультиязычный UI (только русский).
- Автообновление приложения.
- Синхронизация настроек между устройствами.
- Тёмная тема (дизайн фиксирует светлую Fluent/Mica тему).
