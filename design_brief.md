# WorldTimeWidget — дизайн-бриф (для отрисовки в Penpot)

**Дата:** 2026-09-14
**Статус:** ГОТОВО — все 5 экранов отрисованы в Penpot (`http://localhost:9001`, страница «WorldTimeWidget — дизайн (Fluent/Mica)»)

## Решения из уточняющих вопросов пользователю

- **Стиль:** Windows 11 Fluent / Mica — светлая нативная тема, Mica-материал (полупрозрачный, размывающий фон рабочего стола), скруглённые углы, системный акцентный цвет.
- **Поведение окна:** плавающий виджет без рамки (frameless), всегда поверх окон (topmost), перетаскивается мышью за пустую область, живёт на рабочем столе как гаджет Rainmeter. Без иконки в панели задач.
- **Раскладка списка городов:** вертикальный список строк — один город на строку (название + время сверху/сбоку, дата под названием).

## Экраны для Penpot (артборды)

### 1. Основной вид (Default state)
- Компактная карточка, ширина ~260–300px, высота растёт со списком (по 56–64px на строку + отступы).
- Фон: Mica/acrylic — светло-серый с лёгкой прозрачностью (эффект блюра фона рабочего стола за виджетом), обозначить как полупрозрачную заливку #F3F3F3 @ 70–80% + blur-аннотацию.
- Углы: радиус 8px. Тонкая рамка 1px rgba(255,255,255,0.6) сверху для эффекта стекла. Мягкая тень (Fluent elevation, blur 16–24px, низкая непрозрачность).
- Шрифт: Segoe UI Variable (фолбэк Segoe UI). Заголовки строк — Medium 14px, время — Semibold 20–22px (табличные цифры), дата — Regular 11px, вторичный цвет текста.
- Каждая строка города:
  - Слева: название города (и опционально страна/код, серым, мельче).
  - Справа: текущее время в HH:MM (24ч или 12ч AM/PM — уточнить позже в спеке), под ним/рядом — день недели + дата.
  - Индикатор дня/ночи: маленькая иконка (солнце/луна) или тонкая цветная точка слева от названия, если время там ночное (22:00–06:00) — по системному акцентному цвету для "домашнего" города, нейтральный серый для остальных.
  - Разделитель между строками — тонкая линия 1px rgba(0,0,0,0.06), либо просто отступ без линии (решить по факту отрисовки — попробовать оба варианта на артборде).
- Первая строка — «домашний» часовой пояс (время системы), визуально слегка выделена (акцентная плашка слева 2–3px или лёгкий фон).
- Внизу или по hover — едва заметная кнопка "+" (добавить город) и три точки (меню) — показываются только при наведении курсора на виджет, чтобы в состоянии покоя виджет был максимально «чистым».

### 2. Hover / controls overlay
- Тот же артборд с наведением: в правом верхнем углу появляются два маленьких круглых icon-button — «+» (добавить город) и «⋯» (меню: закрепить поверх окон, настройки, выход).
- Кнопки — Fluent-style: круглые, 24×24px, лёгкий фон при hover.

### 3. Добавление города (поиск/выбор таймзоны)
- Всплывающая панель поверх/под виджетом (тот же frameless стиль), с полем поиска сверху ("Поиск города или часового пояса...").
- Список результатов ниже: иконка города/страны (необязательно), название, текущее смещение UTC (например "UTC+3"), при клике — добавляется в основной список и панель закрывается.
- Выбранные города в основном списке — с крестиком удаления при hover в этом же режиме редактирования (или отдельный "режим редактирования" по кнопке "⋯" → "Изменить список").

### 4. Режим редактирования списка (reorder/remove)
- Тот же вертикальный список, но у каждой строки слева — "хваталка" (drag handle, ⠿) для изменения порядка перетаскиванием, справа — крестик удаления.
- Кнопка "Добавить город" в самом низу списка, стиль как пунктирная/ghost-кнопка.

### 5. Контекстное/системное меню («⋯»)
- Простой Fluent flyout-список: "Добавить город", "Изменить список", "Формат времени: 24ч/12ч" (переключатель), "Всегда поверх окон" (галка), "Запускать при входе в Windows" (галка), "Выход".

## Что зафиксировать в самом Penpot-файле
- Единую цветовую палитру и текстовые стили (Fluent-подобные токены: Text Primary, Text Secondary, Accent, Surface, Divider) как Penpot library styles, чтобы потом ими же оформить и код (цвета/шрифты 1:1).
- Компонент "строка города" как переиспользуемый Penpot-компонент (варианты: normal / home / hover-with-delete).
- Артборды 1–5 выше как отдельные фреймы в одном проекте/странице Penpot.

## Результат отрисовки (2026-09-14)

Отрисовано в Penpot (`http://localhost:9001`, файл подключён через Penpot MCP Plugin), страница **«WorldTimeWidget — дизайн (Fluent/Mica)»**, 5 артбордов:

1. **01 · Основной вид** — карточка 288px, вертикальный список 4 городов (Москва — домашний, подсвечен), точка день/ночь, время справа крупным начертанием + UTC-смещение.
2. **02 · Наведение курсора** — та же карточка + два круглых icon-button («+» и «⋯») в правом верхнем углу, появляющиеся по hover.
3. **03 · Добавление города** — панель с полем поиска и списком результатов (город/страна слева, UTC справа).
4. **04 · Режим редактирования списка** — строки с drag-хваталкой слева и кнопкой удаления «×» справа, внизу пунктирная ghost-кнопка «Добавить город».
5. **05 · Меню (⋯)** — flyout: пункты меню, переключатели (Fluent-style toggle) для «Всегда поверх окон» / «Запуск при входе в Windows», шеврон для «Формат времени», акцентный красный пункт «Выход».

Стилевые константы, применённые единообразно во всех экранах: поверхность `#F3F3F3 @ 78–94%` (Mica), обводка-хайлайт `#FFFFFF @ 60%` толщиной 1px, drop-shadow (blur 24–28, offsetY 8–10, чёрный 16–20%), радиус углов 8px (карточки) / 6px (кнопки, поля), акцент `#0078D4`, текст первичный `#1B1B1B`, вторичный `#6B6B6B`, разделитель `#000000 @ 6%`.

**Отклонение от брифа, важное для реализации:** самохостинг Penpot не содержит проприетарный шрифт Segoe UI (это шрифт Microsoft, недоступен через Google Fonts), поэтому в макете использован **Inter** как ближайший нейтральный аналог по пропорциям и начертаниям. В реальном приложении на Windows следует использовать **Segoe UI Variable** (системный шрифт, доступен из коробки) — визуально даст даже более нативный результат, чем в макете.
